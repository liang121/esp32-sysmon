# ESP32 App Home Implementation Plan

**Goal:** 开机显示应用首页，点击 Monitor 进入现有系统与 AI 监控页面，从任一页面可回首页。

**Architecture:** 保留单固件、单主循环和既有绘制接口，在 `main.c` 内增加顶层 `HOME` / `MONITOR` 状态。网络继续后台获取数据；只由顶层状态决定当前绘制、触摸响应及页面切换。

**Tech Stack:** ESP-IDF 5.5.x、ESP32-S3、C、GT911 触摸、现有 RGB565 帧缓冲。执行工具为 `idf.py` 和已安装的 ESP-IDF 环境。

**Spec:** `specs/2026-09-27-esp32-app-home-design.md`

## Global Constraints

- 不更改分区表、NVS 键、串口配置命令、每秒数据获取或 Mac 服务协议。
- `firmware/sysmon/` 是历史 Arduino 版本；只修改 `firmware-idf/` 的当前固件。
- 原厂完整闪存备份可能含 Wi-Fi 密码，不提交也不发布。
- 绘制使用现有字体、颜色和基础图形函数，屏幕为 800×480，不增加图像资源。
- `specs/`、`plans/` 与代码在同一提交中发布。

## Review Focus

- 开机时 Mac 离线：首页仍可正常进入和返回，不被“数据过期”遮挡。
- 点击 Monitor 与点击左上角房子图标：每次只执行一次导航，不触发亮度切换。
- 点击 AI 页 `REFRESH`：仅刷新用量，不误触房子图标或亮度。
- 首页横滑：不会进入 Monitor 或变更监控内页面索引。
- 返回后重进 Monitor：默认系统页、后台数据不断流。

## Task 1：首页绘制与路由

**文件：**修改 `firmware-idf/main/main.c`。

- [ ] 定义顶层状态 `HOME`、`MONITOR`；初值为 `HOME`，保留原有 `page` 作为 Monitor 的两页子状态。
- [ ] 增加首页绘制：`APPS` 标题、整卡可点击的 `MONITOR` 图标和清晰的状态说明；不显示空壳应用。
- [ ] 让 `render()` 在 `HOME` 时只绘制首页，在 `MONITOR` 时绘制现有系统/AI 内容；数据过期遮罩仅针对 Monitor。
- [ ] 编译固件；检查新绘制不越界，现有状态和后台采集仍保留。编译命令在 Task 3 给出。

## Task 2：触摸导航与冲突消除

**文件：**修改 `firmware-idf/main/main.c`。

- [ ] 手指松开时先判定当前顶层状态：在首页，仅整张 Monitor 卡片的轻触可进入 App，并将子页设为系统页；滑动不导航。
- [ ] 在 Monitor 内，优先判定左上角房子图标热区；两页共用该热区。仅未命中返回图标的横滑切换系统/AI 页面。
- [ ] AI `REFRESH` 保留独立热区；只有未命中导航/刷新按钮的短点按才切换亮度。系统页横幅文字、AI 标题各避开返回热区。
- [ ] 核查五项 Review Focus 的完整触摸顺序，确认手势的命中优先级互不冲突。

## Task 3：构建、刷写与设备核验

**文件：**按需要更新 `README.md` 的交互说明；保留 `specs/` 和本计划。

- [ ] 在仓库根目录使用现有 ESP-IDF 工具链运行 `idf.py -C firmware-idf build`；确认无错误且产物适配 `0x300000` 大小的 factory 分区。若未配置工具链，先加载已安装的 ESP-IDF 环境。
- [ ] 用串口 `node mac/configure.mjs status` 记录 Wi-Fi 是否连接与最近取数是否成功，输出时不显示 Wi-Fi 名称或密码。
- [ ] 备妥当前已公开的旧固件源码及本地原厂备份后，重新运行 `arduino-cli board list` 核对串口，使用 `idf.py -C firmware-idf -p /dev/cu.usbmodem11301 flash` 刷写，只更新固件相关分区，不擦 NVS；若串口已变化，替换为实际端口。
- [ ] 设备重启后，确认串口状态与 Mac `/api/now` 正常；验证开机首页、Monitor 卡片、双页面滑动、两页返回、AI 刷新和无网络可导航。无法从串口确认的视觉细节以实机观察核对，并明确记录限制。
- [ ] 将设计稿、计划、README 和固件源码做为同一功能提交推到 `liang121/esp32-sysmon`，核对远端 SHA；不提交设备备份或本地配置。
