# ESP32 USB remote tap plan

1. Add a queued LVGL pointer input that emits press then release, and acknowledge after LVGL handles the release.
2. Add a range-checked `tap x y` USB console command and reuse the Mac serial configurator to invoke it.
3. Build and flash without erasing NVS. Tap safe UI targets over USB, capture the changed pages, and confirm the second tap works.
4. Run relevant checks, audit staged files for sensitive content, and push the source branch. Keep screenshots outside Git.
